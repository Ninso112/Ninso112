<details>
<summary><b>🔍 The <code>*why</code> toolkit: Linux diagnostics that explain instead of just listing</b></summary>
<br/>

| Tool | Answers the question |
|---|---|
| [`rustwhy`](https://github.com/Ninso112/rustwhy) | **All of the below in one Rust CLI**, with 13 diagnostic modules |
| [`cpuwhy`](https://github.com/Ninso112/cpuwhy) | Why is my CPU busy? |
| [`gpuwhy`](https://github.com/Ninso112/gpuwhy) | Why is my GPU idle or overloaded? |
| [`tempwhy`](https://github.com/Ninso112/tempwhy) | Why is my system running hot or throttling? |
| [`iowhy`](https://github.com/Ninso112/iowhy) | Why is disk I/O so high? |
| [`battwhy`](https://github.com/Ninso112/battwhy) | Why is my battery draining so fast? |
| [`sleepwhy`](https://github.com/Ninso112/sleepwhy) | Why won't my system suspend? |
| [`usbwhy`](https://github.com/Ninso112/usbwhy) | Why is this USB device misbehaving? |
| [`mountwhy`](https://github.com/Ninso112/mountwhy) | Why is this mount slow or broken? |

</details>
